# ErlHockey V19.3 — mode standard par défaut

- Combo Builder : mode Standard sélectionné par défaut ; mode Strict facultatif.
- NHL Picks et Sélections gagnantes : mode standard ESPN déjà utilisé, maintenu.
- Joueurs signalés blessés ou incertains par ESPN : exclus.
- Rapprochement des noms abrégés (ex. M. Marner / Mitch Marner) par initiale + nom + équipe.
- Les joueurs absents de la liste ESPN ne sont **pas** confirmés dans l’alignement.
- ESPN absent ou périmé : seuls les joueurs confirmés manuellement restent éligibles.
- Les anciennes tables Supabase et les workflows GitHub Actions restent inchangés.

Déployer les fichiers sur GitHub, puis redémarrer l'application Streamlit. Vérifier les exclusions sur un match connu avant utilisation.
