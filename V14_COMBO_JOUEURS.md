# ErlHockey V14 — Combo Builder Joueurs

Nouveau mode **Joueurs uniquement** : 1+ point, 1+ but, 2+ points, avec historique 5/10/20 matchs, streaks et les cinq profils existants. Le nombre de sélections est ajustable, avec 10 par défaut si au moins 10 matchs sont programmés. Une sélection par match, jamais deux joueurs du même match. Si moins de 10 matchs sont disponibles, le maximum est réduit ; si le profil ne possède pas assez de matchs éligibles, l’option d’adaptation automatique peut réduire le nombre de sélections (minimum 2).

Les modes Matchs uniquement et Mixte restent disponibles. « Suivre ce combiné » enregistre toujours le profil et les sélections dans les tables V14 existantes ; aucune migration SQL n’est requise. Le suivi n'est pas un placement de pari. Les estimations ne sont pas calibrées, et les joueurs peuvent être absents.
